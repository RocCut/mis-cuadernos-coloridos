# Mis Cuadernos Coloridos 📓✨

Una PWA simple y colorida para guardar tus notas, ideas y cuadernos. 
Se instala en el celu y funciona sin internet.

## ¿Qué es?
"Mis Cuadernos Coloridos" es una app web progresiva hecha en HTML, CSS y JS puro. 
Pensada para que puedas organizar tus notas de forma rápida y bonita.

Funciona 100% offline gracias al Service Worker.

## ✨ Características
- **Instalable**: Agrégala a tu pantalla de inicio como una app
- **Offline First**: Tus cuadernos siempre disponibles, con o sin internet  
- **Liviana**: Cero frameworks, carga súper rápido
- **Actualizaciones automáticas**: Te avisa cuando hay una versión nueva
- **Diseño colorido**: Para que sea lindo usarla

## 🚀 Cómo instalarla
1. Entrá a: [https://roccut.github.io/mis-cuadernos-coloridos](https://roccut.github.io/mis-cuadernos-coloridos)
2. En el celu: Menú ⋮ > "Instalar app" o "Añadir a pantalla de inicio"
3. Listo! Ya la tenés como app

## 🛠️ Tecnologías
- HTML5
- CSS3
- JavaScript Vanilla
- Service Worker
- Web App Manifest

## 📝 Cómo actualizar
Cada vez que haga un cambio:
1. Modifico el código
2. Subo la versión en `sw.js`: `cuadernos-v1` → `cuadernos-v2`
3. `git push` y listo
